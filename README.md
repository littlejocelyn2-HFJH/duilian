# 對聯闖關（康軒九年級・對聯單元）

八道關卡＋抽年獸對戰的國文課練習網頁。學生不用登入任何帳號，成績會自動收進老師的 Google 試算表。

| 關卡 | 內容 |
|---|---|
| 一 字字相對 | 名詞對名詞、動作對動作 |
| 二 分辨上下聯 | 仄起平收 |
| 三 入聲字陷阱 | 國語唸平聲、古代是仄聲 |
| 四 找出下聯 | 字數、詞性、平仄 |
| 五 對聯小知識 | 貼法、名稱、應用練習 |
| 六 對聯貼哪裡 | 依場合、行業選對聯（習作題） |
| 七 動手貼春聯 | 上聯貼右、下聯貼左、橫批 |
| 八 抽年獸對戰 | 課本對聯做成牌，右手上聯、左手下聯 |

## 檔案

- `index.html`：遊戲本體
- `config.js`：成績表網址（`sheetApi`）
- `apps-script/Code.gs`：Google 試算表後端

## 一、開啟 GitHub Pages

1. 儲存庫 → **Settings** → 左側 **Pages**
2. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/ (root)**，按 **Save**
3. 等 1～2 分鐘，網址是 `https://littlejocelyn2-hfjh.github.io/<儲存庫名稱>/`

## 二、部署成績後端（Google 試算表）

1. 新增一個 Google 試算表（名稱自訂，例如「對聯闖關成績」）
2. **擴充功能 → Apps Script**，刪掉原本內容，貼上 `apps-script/Code.gs` 全部內容
3. **把第 8 行 `change-me` 改成自己的密碼**（維持 change-me 的話，老師永遠登不進去）
4. 右上 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 存取權：**所有人**
5. 第一次會要求授權，按「允許」（若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往（不安全）」，這是自己的程式）
6. 複製結尾是 `/exec` 的網址，填進 `config.js` 的 `sheetApi`
7. 直接用瀏覽器打開這個網址，看到 `{"ok":true,...}` 是正常的，那是後端

試算表會自動建立兩個工作表：
- `data`：給程式讀，每位學生每一關一列（請不要手動修改）
- `作答紀錄`：給老師看，每次作答一列，可以直接篩選

### 之後如果改了 Code.gs

1. 重新貼上 Code.gs
2. **再改一次第 8 行密碼**
3. **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**

網址不會變，不用改 config.js。

## 三、老師怎麼看成績

- 成績頁：`網址#scores`（學生登記視窗下方也有「我是老師，先略過」連結）
- 輸入密碼登入後，會多出：
  - 排行榜的「最後作答時間」「疑似亂答次數」
  - **作答紀錄**：最新在上，可篩座號、只看疑似亂答、調整秒數門檻、複製到 Excel
  - **各關分析**：作答人數、平均星星、答對率、最常答錯的題目
  - **學習單**：每位學生「今天學會了」與「最有收穫的事」
  - **教師區**：匯出 CSV、匯入成績碼、清除本班成績
- **大屏**：登入後按「開啟大屏」（`網址#screen`），每 15 秒自動更新。只顯示人數、排行榜前 5 名、各關答對率、學生金句，不顯示用時或亂答資訊。

## 注意事項

- 學生第一次打開要填班級、座號、姓名，會記在該裝置；共用裝置換人時按首頁「換人」。
- 每關取最高星星累計，滿分 24 顆；每人每關保留最近 20 次作答。
- 抽年獸只有「對電腦」會記成績，兩人對戰不記。
- 疑似亂答（用時少於門檻，或每題選同一位置卻沒全對）只是提醒，請老師確認。
- 學生連不上成績表時，結果畫面會出現「成績碼」，請學生複製給老師，老師在教師區匯入。
- `config.js` 留空時是「本機模式」：成績只存在學生自己的裝置。
- 更新後如果畫面沒變，按 **Ctrl + F5** 強制重新整理。
